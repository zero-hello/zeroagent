## 功能移除與設定注意

本版不新增功能退役；先前移除的 Hey Zero、獨立系統語音助理、產品 Web 伺服器、子代理設定檔及設定內翻譯／圖片／影片獨立入口不恢復。原生通話、Agent、Android Shell 與對話內圖片支援保留。

- 效率工具從附件面板進入會攜帶目前對話；由設定或小工具進入時沒有指定對話。
- 舊附件搜尋請先重建索引；新日期條件篩選的是更新時間，並以 UTC 日期計算。
- 備份請包含「設定／CONFIG」，才能一併保存新專案、文件、標籤、分享紀錄和對話記憶偏好；模型權重不因這個選項自動備份。
- 圖片問答需要已設定且標記支援圖片輸入的聊天模型。媒體預覽留在本機，只有按下詢問才發送一張圖片。
- S3 分享沿用備份設定，需私人桶；切換桶後不能用新位置撤回舊連結，須恢復原設定。連結到期不等於刪除物件。
- 簽章與包名維持相容；安裝新版前仍可先做 App 備份。
