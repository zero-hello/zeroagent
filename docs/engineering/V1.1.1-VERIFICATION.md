# v1.1.1 原生 UI 整合驗收

已推送整合分支並建立 [PR #3：精修 Android 原生 UI，適配 v1.1.1 並修復測試與 Lint](https://github.com/zero-hello/zeroagent-private/pull/3)，目標分支為 `main`。未合併或發布正式版本。

依使用者後續要求，整合基底更新為 `origin/main`／`v1.1.1` 的 `aba9ba6377637e2e20fee5b6b62a177d3ad6ef1b`。提交前再次 fetch 確認遠端與此版本一致。本輪保留新版情境記憶、Gemini 帳號、統一原生語音、模型參數與側欄分頁／喚醒修復；不恢復上游已退役的 Telegram、舊 ASR、助理身分編輯等流程。

## 適配內容

- 保留可換列、48dp 的聊天操作、直接模型／推理／存取控制，以及生成期間停止與下一則草稿並存。通話沿用新版單一原生語音入口。
- 推理程度改寫入目前模型的 `generation.reasoningLevel`，與 1.1.1 模型權威一致。新增持久化 JSON 往返、畫面投影讀取、其他模型隔離與工具／記憶 profile 不變的回歸測試。
- 保留新版側欄的分頁與全部對話範圍，沿用 840dp 常駐側欄及各區獨立捲動；移除重複品牌及已退役的舊選擇器。
- 六群設定分類與搜尋使用同一份目錄，對接模型記憶、Gemini 帳號與統一語音設定。39 個固定目的頁，加目前模型記憶共 40 頁；開發模式入口另計。
- 共用 CardGroup 同時支援新版玻璃材質、窄視窗／大字體排列，以及不需要堆疊時的 opt-out；保留內縮分隔線與一致間距。
- 對齊上游 376 個品牌資源重新命名，移除 416 個重複定義，保留仍需要的補充翻譯。3,544 個英文基底字串在六個非英文目標語系均完整覆蓋，沒有重複鍵或格式參數不符。
- 延續前輪 Windows JSON 路徑、CRLF fixture、shell 與 Android POSIX 符號連結測試修復。rootfs 架構政策採最新上游實作；不以過時 fallback 覆蓋新版拒絕未知架構的行為。
- 全模組 Lint 實際找出新版另外 7 個錯誤，已修正數字控制的配置感知、Google 匯入／權限失敗提示的資源取得，以及模型參數條件的誤導縮排。相同小數語系切換測試在舊 APK 失敗、新 APK 通過，並驗證語系切換不改寫模型、當地小數輸入才更新指定參數。
- 重跑發現上游記憶裝置測試會受到 UI fixture 留存資料影響。測試先限定 `app.zeroagent.debug`，再於既有 try／finally 範圍內清除測試記憶索引；保留模型、全部斷言及正式檢索實作。

相對 `v1.1.1` 整合基底，沒有改動資料庫 schema、備份格式或工具核准／授權規則。新版上游自身的 schema 32 遷移及資料清理完整保留，會納入裝置測試。

## 重現與產物

```powershell
.\gradlew.bat testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest :workspace:assembleDebugAndroidTest lintDebug --continue --no-daemon --max-workers=1
.\gradlew.bat :app:assembleDebugAndroidTest lintDebug --continue --no-daemon --max-workers=1
python scripts/verify_android_locales.py --json build/ui-polish/v111-locales-final.json
python scripts/provision_memory_test_model.py --serial emulator-5556 --model build/ui-polish/v111-model/multilingual-e5-small-q8_0.gguf
python scripts/verify_apk_native_alignment.py app/build/outputs/apk/debug/app-arm64-v8a-debug.apk app/build/outputs/apk/debug/app-x86_64-debug.apk --json build/ui-polish/v111-native-alignment.json
```

模型來源 URL 與校驗值由 `MemoryManager` 固定；部署腳本會先檢查本機模型，再檢查獨立 Debug 套件內的 SHA-256。Windows 下採用二進位 `adb push`，不透過可能在控制字元截斷的 shell stdin。

本機交付目錄為 `release-artifacts/v1.1.1-ui-hardening/`，包含兩種架構 APK、SHA-256、原始驗證日誌、Lint 報告與截圖。APK 及模型不提交至 Git。專用模擬器的尺寸、字體與動畫設定已還原，驗證完成後已關閉。
