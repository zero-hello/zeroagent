# v1.0.9 原生 UI 整合與驗證

此為切換至 v1.1.1 前的歷史紀錄。v1.0.9 最後一輪 Lint 程序在 app 分析時中斷，沒有最終成功結果；不以本輪紀錄代表 v1.1.1 的驗證或交付。

本輪以 `origin/main`／`v1.0.9` 的 `0143164012b6184aefcd176b4e86f714c1d866aa` 為整合基底，保留新版系統語音助理與 Hey Zero 功能，並將語音助理納入既有設定分類及搜尋。驗證使用獨立套件 `app.zeroagent.debug`（1.0.9／versionCode 10），沒有發布正式版本。

## 修復內容

- 原先 71 項 JVM 失敗：Windows 路徑直接插入 JSON、安裝測試硬編碼路徑，以及最小 shell 缺少外部 `sleep` 等測試環境假設。改用 JSON 建構器、暫存目錄及 POSIX shell 內建指令，保留原本的內容、逾時及輸出斷言。
- 全模組驗證另外發現 38 項既有失敗：highlight fixture 的 CRLF／LF 差異及 workspace 的 Unix shell／symlink 假設。Fixture 仍逐 token 精確比對，另驗證 CRLF 來源可還原；POSIX 權限與符號連結斷言移至 Android 實際檔案系統執行，沒有略過測試。
- 路徑防護同時 canonicalize 路徑與受保護前綴，以路徑片段判斷邊界。保留穿越、NUL、其他套件及解析失敗的拒絕行為；新增 Android `/data/data` 與 `/data/user/0` 別名測試。工具核准規則、授權設定與執行流程未變更。
- 補齊六個非英文目標語系的資源繼承與翻譯，七種介面語言均覆蓋 3,352 個基底字串；驗證重複鍵及格式參數。修復資源讀取未隨配置更新、Activity 取得方式、通知／定位權限檢查與診斷字串型別。
- 修復 v1.0.9 語音設定直接讀取 `Context.configuration`，並為 LiteRT inference hint session 清理補上與建立時一致的 SDK 33 條件。沒有降低 minSdk 或移除相關功能。
- 語音設定的四組動作改為可換列排列，320dp／200% 字體下按鈕文字仍可閱讀。相同 Compose 測試在舊排列失敗（「試用助理」擠成四行），修正後通過；測試檢查實際字形邊界、行數、完整文字及按鈕高度。
- Debug context 測試使用實際 `BuildConfig.APPLICATION_ID`，不再誤認為正式套件。

沒有新增 Lint baseline、停用問題類別或 blanket suppression。公開 API、資料庫、備份格式與工具授權規則相對整合基底保持相容。

## 可重現的命令

使用 JDK 21，於專案根目錄執行：

```powershell
.\gradlew.bat testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest lintDebug --continue --no-daemon --max-workers=1
python scripts/verify_android_locales.py --json build/ui-polish/v109-locale-coverage.json
python scripts/verify_apk_native_alignment.py app/build/outputs/apk/debug/app-arm64-v8a-debug.apk app/build/outputs/apk/debug/app-x86_64-debug.apk --json build/ui-polish/v109-final-native-alignment.json
python scripts/android_ui_matrix.py emulator-5556
```

裝置測試分組執行以保持 Activity、Compose 測試與設定目錄巡覽彼此獨立，完整 runner 輸出隨交付附上。workspace 的重現步驟見 [TESTING.md](../../workspace/TESTING.md)。

## 交付與實機範圍

本輪原始驗證證據保留在 `build/ui-polish/v109-*`，不另外交付已過時的 APK。使用者後續要求改以 v1.1.1 整合與交付；新版須重新建置並驗證，APK 不提交至 Git。

專用模擬器可驗證版面、導覽、資料庫／備份回歸與 Linux 檔案語義。實際麥克風、藍牙路由、系統助理喚起／背景常駐、Hey Zero、Shizuku 及需要供應商憑證的連線行為仍需真機或相應環境驗證，不能由這些結果推論已完成真機驗收。既有 v1.0.9 語音 QA 要求繼續適用。

本分支包含先前已存在的 rootfs 架構預設修復（與既有 PR #2 重疊）及 Windows pnpm 建置修復；本輪未關閉或修改其他 PR，也未發布或合併版本。
