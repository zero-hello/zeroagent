# 共用介面與無障礙版型

使用現有 Jetpack Compose 與 Material 3 Expressive。色彩、字體、形狀與動態由
`ZeroAgentTheme` 統一提供；不以玻璃、模糊或透明疊層建立產品風格。

## 共用元件

| 元件 | 用途與約定 |
| --- | --- |
| `CardGroup` | 設定分組，外側 28dp 圓角；窄螢幕或大字體時將控制項移到說明下方。 |
| `ExpressiveDivider` | 設定列、選項、選單與內容區的分隔。預設 1dp、完整 `outline` 語意色、左右 16dp 縮排，隨明暗主題切換。 |
| `SettingsActionCard` | 圖示、標題及說明放在內容卡；按鈕放在卡外的獨立操作列，空間不足時換行。內容以讀屏群組呈現，狀態可選擇禮貌播報，按鈕保留自己的名稱與焦點。 |
| 共用 `Switch` | 委派官方 Material 3 Switch 處理按壓、焦點、停用、讀屏狀態與動態；維持至少 48dp 點擊範圍。靜態狀態指示仍提供勾選狀態。 |
| `Select` / `SelectTextField` | 共用選單分隔及選取狀態語意；文字輸入選單保留不依賴 ExposedDropdownMenu 的定位方式。 |
| `AppDrawerHost` / `LocalAppDrawer` | 導航層持有唯一抽屜狀態；聊天與設定首頁開啟同一份內容，寬畫面使用永久側欄。側欄使用 Activity 範圍的 `ChatDrawerVM`，不建立第二份 `ChatVM`。 |

新增相同結構時先使用或擴充這些元件，不要在各頁複製一份版型。供應商等特殊表單仍須保留其實際功能與有效狀態；沒有可用功能時，應說明原因或隱藏入口。

## 主要畫面

- `WorkspaceWelcome` 的四個快捷動作使用同一個 FilledTonalButton 元件及官方按壓形狀。依可用寬度與系統字級，保持完整的四欄、兩欄或單欄，文字可以換行。
- 無障礙設定頁用 `SettingsActionCard` 將內容區與操作區分開。服務狀態從實際服務及系統設定更新；修復及診斷進行時顯示忙碌文字並停用重複操作。
- 診斷截圖在背景執行緒寫入應用程式私人快取，成功與失敗顯示實際結果；取消仍向上傳遞，Bitmap 在完成後釋放。
- 系統無障礙、電池及浮動視窗授權仍由 Android 管理；應用程式不能把顯示中的狀態當成繞過系統授權的依據。

## 驗證入口與範圍

- `WelcomeActionLayoutTest`：窄螢幕、一般手機及較寬畫面，在一般、大字體與極大字體下的欄數。
- `CardGroupLayoutTest`：共用設定列在窄螢幕與大字體下移動控制項的邊界。
- 必須編譯正式 App，確認共用元件的 Material 3 API、資源與所有呼叫點可整合。
- 裝置檢查需包含淺色、深色、320／360／840dp、直向／橫向、1.0／1.3／2.0 字級、鍵盤開啟與關閉，以及讀屏與鍵盤焦點。
- 分別驗證首頁、對話、側欄、設定、供應商、權限、工具選單及終端機。確認長文字可捲動、操作不重疊、焦點可辨識、狀態有名稱且不用顏色獨自表達。
- 從聊天進設定後開啟側欄，確認選擇聊天、新增、工作區、設定、關閉與返回都正常；旋轉切換永久／彈出模式後不意外重開，設定子頁仍使用返回。
