# AI Agent 與授權裝置驗收清單

本清單只描述目前功能的驗收步驟，不延用歷史版本的通過結論。實際結果須對應本版 APK、裝置、時間與證據。已移除的「子代理設定檔」設定頁不再作為操作入口；既有 AI Agent、子代理執行與資料相容性仍需確認。

## 驗收準備

- 記錄產品版本、APK SHA-256、套件名稱、裝置型號與 Android 版本。
- 使用測試資料與獲授權的供應商帳戶；證據遮蔽金鑰、私人對話及裝置個資。
- 記錄新安裝或升級流程，確認測試執行前的存取模式、工具授權與系統權限。
- 每項記錄操作、預期、實際結果及證據。沒有執行時保持「待執行」。

| 項目 | 操作與預期 | 結果 |
