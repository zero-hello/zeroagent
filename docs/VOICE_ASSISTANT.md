# ZeroAgent 語音指南與相容說明

獨立系統語音助理已移除。文件檔名保留供既有連結使用，不再代表可用的 Android 系統助理功能。

## 保留的語音功能

一般聊天內的原生即時通話與文字朗讀 TTS 保留。「設定 → 語音服務 → 語音對話」管理通話供應商、API Key、Base URL 與相容模型；模型資料與協定探索只表示端點宣告，實際可用性仍須由通話握手確認。

OpenAI Realtime、Gemini Live 與相容安全 WebSocket 端點可依既有流程使用。僅提供文字、STT 或 TTS 的服務不應當成原生雙向模型。TTS 是獨立朗讀能力，與模型原生音訊分開設定。

通話中的麥克風、中斷、結束、字幕及輸出裝置仍由通話畫面管理。聲音品質、回音消除、藍牙、音訊焦點與延遲受硬體及供應商影響，需依[裝置驗收清單](VOICE_ASSISTANT_QA.md)驗證。

## 已移除的功能

- Android 系統數位助理角色、系統助理視窗與獨立測試入口。
- Hey Zero 背景喚醒、常駐錄音、喚醒通知及背景服務。
- 個人聲學範本錄製、訓練、試聽與相關設定。
- 系統助理膠囊及其獨立互動流程。

不再需要為上述功能將 ZeroAgent 設為預設系統助理。手機工具與一般文字 Agent 的權限機制不因此移除。

## 升級與既有資料

升級會忽略或清理已退役功能專用的設定及資料；既有聊天、供應商金鑰、一般語音通話與 TTS 設定依各自儲存與遷移流程保留。舊備份中的語音助理識別字僅用於相容或移除舊資料，不會重新建立功能入口。

一般通話仍需 Android 麥克風及供應商相關權限；停用或撤銷權限時應回報原因並停止本次錄音。指令音訊會送往使用者選定的通話端點，請依帳戶服務的資料政策與費用使用。

## 驗證範圍

實際建置、單元測試與裝置結果以當版交付報告為準。此指南描述功能邊界，不宣稱真實人聲、背景耗電、耳機或付費 API 已通過驗收。
