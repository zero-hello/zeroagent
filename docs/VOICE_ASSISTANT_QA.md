# 原生語音與語音助理移除驗收

本清單是待執行的驗收步驟，不是測試通過紀錄。執行後應記錄 APK 版本、簽章、裝置型號、Android 版本、時間、供應商／模型及實際結果，憑證不得出現在證據中。

## 移除驗收

- [ ] 設定、搜尋、導航與系統入口均不再提供獨立語音助理。
- [ ] Manifest 不再註冊專用 VoiceInteraction／喚醒服務。
- [ ] 新安裝與升級後均不啟動喚醒通知、背景錄音或喚醒範本流程。
- [ ] 匯入含舊語音助理設定的備份後，不恢復已移除入口；聊天、一般通話與 TTS 資料保留。

## 證據與限制

至少在 Android 12 與較新 Android 的實體裝置驗證麥克風、音訊輸出、焦點與背景生命週期。付費端點只使用獲授權帳戶，不把本機假回覆或合成波形當成真實通話證據。

編譯、簽章及模擬器畫面通過，不能替代真實人聲、硬體回音消除、延遲、耗電及 OEM 行為。未測項目保留「待執行」，失敗須附重現步驟。
